# 数据目录

`host.lock` 是永久保留的锁文件 inode，不是 PID 文件。`serve` 在整个运行期间持有操作系统独占锁；同一目录上的第二个 `serve` 或身份升级会被拒绝。进程退出（包括崩溃）时，操作系统释放锁；主机运行期间不要删除该文件。旧版本没有这把锁，也必须停止；升级命令还会检查旧版的管理监听器。`infercat identity upgrade` 要求主机停止，只保存一次 `host.key.json.pre-ic2` 且不覆盖，然后原子写入第二版身份。不要用旧版程序运行已升级的身份：旧版会忽略标记，以同一把密钥提供旧格式身份，导致 `ic2` 邀请在握手时静默失败。

默认目录：macOS 为 `~/Library/Application Support/infercat`，Linux 为 `~/.config/infercat`，Windows 为 `%AppData%\infercat`；也可用 `--data-dir` 指定。

| 文件 | 作用 |
|---|---|
| `host.key.json` | 主机身份。请备份，不要同步；删除会使所有已发出的邀请失效。 |
| `host.lock` | 运行中的主机持有的独占系统锁；保留该 inode。 |
| `host.key.json.pre-ic2` | `identity upgrade` 创建的一次性旧身份备份。 |
| `keys.json` | 好友密钥的哈希（不保存密钥明文）、状态和限额。 |
| `usage.jsonl` | 每次请求一行：密钥、接口、状态、token 数和耗时。除非开启 `serve --log-prompts`，否则没有提示词内容。 |
| `admin.sock` / `admin.port` | 本地管理端点：Unix socket，或 Windows 回环端口记录。 |
| `admin.token` | 每次运行新生成的本地管理 bearer（0600），关闭时删除。 |
| `admin.json` | 可选远程控制台开关：管理码的 SHA-256 哈希和启用时间，权限 0600；不保存明文或好友密钥。关闭远程访问时删除。 |
| `bridge.json` | 公共桥接端点、主机 id 和秘密桥接 token（0600）。由 `expose --register` 创建，`serve` 启动或重新加载时读取，`expose --off` 删除。请保密。 |
| `runs/<key-id>/state.json` | 每把密钥的任务输入、输出、尝试记录、计量、审批和保留事件。 |
| `runs/<key-id>/images/<run-id>` | 生成的 PNG/JPEG：每张最多 8 MiB，7 天过期，每把密钥独立的 256 MiB 图片预算（先淘汰最旧输出）。见[图片主机配方](IMAGES.zh-CN.md)。 |
| `config.json` | 保存的 `serve` 参数、活动 `profile_install`，以及 `search.key_file`（单独存放的服务商密钥路径）。 |
| `profiles/downloads/` | 按 SHA-256 寻址的已验证下载和可续传的 `.part` 文件；不安装到系统。 |
| `profiles/trees/` | 私有解压的模型、引擎和固定版本辅助程序/运行环境。成功 setup 会清理新清单不再引用的目录；检查失败仍保留已验证下载。 |
| `profiles/install-<sha256>.json` | 版本化安装记录：配置档摘要、规范路径、模型/辅助程序/运行环境文件哈希、符号链接目标、外部所有权、不可用原因及实际命令。配置指向活动记录。 |
| `profiles/members/<id>/` | 生成的引擎配置、隔离的 HOME 和 `engine.log`（达到 1 MiB 后回绕）。 |
| `agent/runtime-<harness>-node<version>/` | 私有安装的固定版本 Node/harness、完整性锁和安装标记。 |
| `agent/npm-cache/` | 已锁定完整性的 harness 软件包安装缓存。 |
| `agent/workspaces/run-*/` | 每次任务的临时文件、`tmp/` 和 `.runtime/`；捕获输出且子进程结束后删除。 |
| `tunnel.log` | 隧道引擎日志（`serve --verbose` 改为直接打印）。 |

`infercat serve -h` 也会列出这些文件。见[主机快速上手](../README.zh-CN.md#快速上手主机端)。

控制台在所有平台都使用 `admin.token`：每次运行生成随机 bearer，权限 0600，管理服务关闭时删除。控制台地址保存在现有 `config.json` 的 `console` 字段；实际监听地址位于需认证的 `/status`，因此端口 0 也支持 `infercat console --print`。不新增状态文件。

远程访问默认关闭，需在本地启用；`admin.token` 始终是独立的逐次运行回环凭证。轮换原子替换已保存的哈希；使用中标记只在内存中保留，十分钟后失效。远程控制台开关跨重启保存在 `admin.json` 中。文件损坏或不可读时，`serve` 仍会启动，但远程访问关闭。启动提示和设置会列出文件及修复方式：重新启用远程访问以生成新管理码。损坏文件保留到这个明确操作原子替换它；修复失败会报告。

运行中的无界面主机可用 `infercat remote on --data-dir DIR` 启用访问，获取只返回一次的管理链接/码和终端二维码。粘贴到网页版或打开链接即可进入 `/console`。`remote rotate` 更换管理码，`remote off` 禁用访问，`remote status` 只报告状态，不返回管理码。这些命令要求回环控制台监听器开启，并通过已认证的本地管理 API 操作。`--json` 为脚本返回结果，`--no-qr` 省略二维码。on/rotate 输出是秘密；命令不会自动重试结果不确定的操作。结果丢失时先检查状态，再 rotate 获取新码。

新的 `usage.jsonl` 行含每个资源类别的 `meters`：单位、测量值和计费值。`ts` 仍是请求开始时间，`settled_at` 将费用计入结算当天的 UTC 日预算。主机从已记录费用恢复每日预算，包括零计费拒绝和被截断的非流式请求所扣除的预留量。没有 `settled_at` 的旧行使用 `ts`；没有 meters 的行沿用测量值等于计费值的解释，旧 token/音频遥测仍可读。不迁移文件：`keys.json` 保留现有限额字段，在内存中解释为资源预算，读取不会重写文件。

### 任务状态

`runs/<key-id>/state.json` 是每把密钥的原子快照，包含输入、输出、尝试轨迹、捕获的文件内容、审批问题和答案、生命周期元数据以及最近 256 个生命周期事件。目录权限 0700，文件 0600。身份只保存密钥 ID，任务元数据不保存 bearer 秘密。任务内容是用户数据，不受 `usage.jsonl` 的可选提示词日志开关控制。快照损坏时仅拒绝该密钥，绝不静默替换为空存储。

固定上限：每步输入和输出各 1 MiB，每把密钥 64 MiB 快照、100 个保留任务、16 个活动任务，每台主机 64 个活动任务。达到上限时拒绝新增，不裁剪现有工作。终态内容在完成或取消后最多保留 7 天，也可由主机所有者提前清除。活动任务最长 24 小时，清理会取消被遗弃的等待。启动恢复会中断未完成任务，不重放引擎工作；终态快照保留到过期。主机启动时及每分钟执行过期清理。没有 CLI 参数改变这些常量。

普通写入预留 64 KiB 终态空间。旧的满额快照无法保留新终态输出时，会记录明确的 `output not retained: budget` 标记以及最小终态/用量更新。更新每个任务最多超出普通预算 4 KiB，每把密钥的例外总量最多 400 KiB。同一快照中的私有逐任务字节计数跨重启保留，后续生命周期写入不会重置；其中 512 字节留给终态结算。生命周期更新仍放不下时，任务以 Failed 和 `storage exhausted` 结束，记录拒绝，停止继续派发或审批。达到绝对上限时，终态写入可删除最旧的重放事件（旧游标收到 Reset），但不能删除累计尝试、用量、捕获输出或图片元数据；新保留内容会被拒绝。过期时连同任务删除计数；被拒绝的新任务准入不会使用此路径。磁盘/目录故障仍会拒绝该密钥并记录错误，但不会阻止主机启动或健康密钥的过期清理。快照首次使用时加载，无活动任务或订阅者且闲置 5 分钟后释放内存。

图片任务将 PNG/JPEG 内容私有保存到 `runs/<key-id>/images/<run-id>`，快照只保存输出元数据。单张最多 8 MiB，每把密钥独立的图片预算 256 MiB，先淘汰最旧输出，与 64 MiB 状态预算分开。输出最多保留 7 天，也可由主机所有者提前清除；Discard 立即删除输出。任务元数据和 output-gone 标记保留到任务过期或被清除。清除后的任务返回 not-found。启动清理会处理有删除依据的路径；中断工作绝不自动重放。

图片预算计算仍保留且可读取的输出。无法删除的旧文件会记入日志并在下次清理时重试，暂时可能产生预算之外的磁盘占用。`infercat status` 分别报告有删除依据的待清理路径及仅供人工检查的孤立文件。仅观察到文件不构成自动删除授权；有依据的重试路径保持其删除权限。

缩小快照的提交不受保留字节预算限制，包括超过普通上限时的过期清理。有界生命周期记录同时覆盖 Waiting 和终态，降级写入保留图片元数据和计量身份。预算拒绝不会把密钥标为损坏。过期清理及删除任务的 clear 会先将所有被删除任务 ID 作为清理意图一并提交，再删除文件；已有删除依据的路径也可不提交快照而直接重试。空快照不能授权目录扫描删除未知图片文件；这些文件保留并记录。

控制台 Stored 区域显示每把密钥缓存的状态文件字节数和可读取图片字节数。Clear 删除终态任务及其保留内容/图片，保留活动任务和仍未结束的 worker，并报告仍待清理的文件；不删除密钥或工作目录。

热 Stored 读取最多扫描 MaxRuns（100）条记录和主机范围内跟踪的清理路径，不扫描文件系统。列表和大小在读取时从缓存快照及有界保留内容计算；提交时只缓存已编码的状态文件字节数。冷密钥还会加载有界状态文件，并扫描该密钥目录内的状态写入临时文件。普通上限不包含预留的 64 KiB 终态空间，活动预留量和例外超额单独显示。Clear 将已验证的任务清理 ID、任务删除和 epoch 重置原子提交，只处理有删除依据的路径，并持久化移除成功的意图。空快照中的未知图片仅作报告，与有依据的重试路径分开；状态同时计数，但观察本身从不授权删除。抽屉单独显示待人工检查数，clear 只重试有依据的路径。只有删除任务才重置 epoch，纯清理重试保留游标。目录不存在不是错误。

Stored 读取保留原先的访问时间，所以轮询不会把密钥固定在内存中。过期清理将有依据的清理意图随缩小提交一起保存；图片元数据提交失败时会尽力删除自己创建的文件，失败则记为有依据的重试。

管理字段 `image_cleanup_pending` 现在只计有依据的重试路径，旧主机曾把观察项也计入该字段。`image_orphans_for_review` 单独统计仅供检查的文件。快照仍有任务时会清理未被记录命名的图片；只有空快照把未知文件留待人工检查。状态目录及图片目录中属于本程序的 `.run-*` 写入残留会在加载或清理时回收，失败会记录并在后续扫描重试。

### 智能体工作目录

`agent/workspaces/run-*/` 是每次任务的临时工作目录，含私有 `tmp/` 和 `.runtime/` 配置/状态。受限子进程可读写自己的工作目录，不能访问其他任务的目录或主机任务/密钥记录。捕获输出保留且子进程结束后，工作目录删除；只有捕获副本留在 `runs/<key>/state.json`。主机崩溃或已报告的清理失败可能留下不再复用的目录，供操作员回收。早期逐密钥工作目录保持不动。已安装的运行环境在子进程内只可读/执行；Exa 密钥通过一次性继承描述符传入，不写入状态文件或子进程环境。精确的系统目录及网络限制见[智能体运行环境](AGENT-RUNTIME.md)。
