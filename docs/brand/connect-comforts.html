Connect card, before and after

One: the mark sits at 48 px above the wordmark, so the card has an anchor before its first word. Two: the invite field carries a Paste ghost button at its top-right, inside the frame, where a thumb reaches it first on a phone. Three: a one-line mono hint under the field says what the field is waiting for, confirms a code that reads as an invite along with its host prefix, and names the problem when it does not. Four: a quiet line after the actions tells a reader with no code where to get one, or how to host their own. Five: the Tailscale attribution leaves the card for an About disclosure in the footer, which now reads Version 0.0.1-dev · MIT · Source on GitHub · About.
