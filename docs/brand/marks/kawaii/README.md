# Big-eyed marks (2026-09-06, drawn by the PM)

Founder's reference: a kawaii cat — wide head, eyes nearly half its width set low, a large pupil with a
highlight, small ears at the corners, peeking over an edge with two paws. Five marks at that proportion
in the Swiss one-colour idiom (`gen3.py` regenerates them; `sheet.html` shows every size and ground).
PM recommendation: `face` for the favicon and every mark under 48 px; `peek` large (connect page, OG,
README). The chosen file becomes `web/public/favicon.svg`; `make brand` regenerates every raster.
