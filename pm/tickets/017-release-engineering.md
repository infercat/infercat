# 017 — Release engineering (no publishing)

## Binding

**Why.** Strangers need a download, and the BSD-3 licences of tailcat/tailscale (and the rest of the
dependency tree) require notices with every binary. This ticket makes releases *reproducible and
legal*; it publishes nothing (founder gates distribution, license, and the name — pm/LAUNCH.md F1/F4/F5).

**Promises.**
1. `.goreleaser.yaml` builds `bunny-network` for darwin (arm64, amd64), linux (amd64, arm64), windows
   (amd64) with `-trimpath`, `-s -w`, and `-X internal/product.Version=<tag>`; archives per platform
   named from `product.CLIName`; a checksums file. `make release-dry` runs `goreleaser release
   --snapshot --clean --skip=publish` from a fresh clone and prints the artifact list. No `publish`
   configuration is committed (a later ticket adds GitHub Releases/Homebrew once the founder decides).
2. `THIRD_PARTY_NOTICES.md` generated by `go-licenses report` (or `go-licenses save` into the
   archive) covering the Go tree, plus the web bundle's dependencies via `pnpm licenses list --json`;
   a test or `make notices-check` fails if a dependency's licence is unknown or non-permissive.
   BSD-3 notices for `tailscale.com` and `github.com/tailscale/tailcat` are present verbatim.
3. `bunny-network version` prints `product.Name product.Version (commit, date)`; the web app's
   footer/About shows the same version from a build-time constant (`VITE_APP_VERSION`), so a bug
   report can name both halves.
4. The archives include `README.md`, `THIRD_PARTY_NOTICES.md`, and the `web/dist` bundle is built and
   attached as a separate `web-<version>.zip` artifact (so a host can self-serve the app).
5. Evidence: `make release-dry` output from a fresh clone under
   `/Users/yuanpingsong/.claude/jobs/12b4a99c/tmp/rel-clone`; the notices file's licence histogram;
   `bunny-network version` output from the darwin artifact.

**Size 2** (≤400 lines incl. YAML). Concept budget 0. **Normal**.

**Scope contract.** `.goreleaser.yaml`, `Makefile` (new targets only), `THIRD_PARTY_NOTICES.md`,
`internal/product/product.go` (Version/Commit/Date vars settable by ldflags), `cmd/bunny-network/main.go`
(`version` output only), `web/src/product.ts` + `web/vite.config.ts` (version constant), a small
`hack/notices.sh`. Do not add a LICENSE file (founder decides). Do not publish anything anywhere.
