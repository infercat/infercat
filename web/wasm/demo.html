wasm bridge demo

Run go run ./hack/tunneldemo, paste the address it prints, Connect. The page loads /public/bunny.wasm, connects once, then dials port 80 for each request: a raw GET /healthz, a second one (no new handshake), and GET /stream (20 SSE events). Add ?addr=…&auto=1 to the URL to run it unattended (see demo-check.mjs).
